# Prompt Writer — Phase 3: RULE SYNTAX

**IN:** Phase 2's deliverable, or the plan a mode handed in. **OUT:** the drafted text and the deliverable below.

## Steps

1. **ALWAYS write every binding rule with one of the four openers, in the form of the format guide.** A clause that
   cannot take one is knowledge: place it in the skill that owns the topic, not in a rule.
2. **WHEN a rule needs an exception, a fixed premise, a stop condition or a fallback ⟶ use the matching
   control-flow word** inside the rule.
3. **ALWAYS put each technique Phase 2 picked where its judgement or trap sits** — exact cases at the fuzzy
   boundary, the output skeleton followed by one real instance, reasoning fields before verdict fields.
4. **WHEN the content governs another agent's model tier ⟶ name the archetype and its tier from
   ref:skill/grimorio.agent-tiers#the-scale-task-archetype--tier.**
5. **WHEN a clause cannot be written without inventing what it should say ⟶ drop it and list it in REFUSALS.**

## Deliverable

```
RULES DRAFTED:       <count, and the opener each uses>
TECHNIQUES APPLIED:  <one line per Phase 2 pick: where it landed>
REFUSALS:            <clause and why | "None">
```

Example:

```
RULES DRAFTED:       2 — WHEN (quote the flagged line), ALWAYS (state the measured ratio)
TECHNIQUES APPLIED:  K7 ⟶ EVIDENCE field before SEVERITY in step 4; K2 ⟶ two exact contrast cases under step 4
REFUSALS:            None
```
