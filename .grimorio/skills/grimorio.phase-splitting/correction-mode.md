## The general pattern

The general pattern this file names: a phased agent's own coordinating caller declaring a narrower entry
mode that skips a phase whose ENTIRE job is RE-DERIVING a fact or plan already decided elsewhere — never a
phase whose job is RE-VERIFYING the actual returned artifact. The distinction is the whole mechanism: RE-DERIVATION (precedent search, exemplar
search, an objective/exit-condition restatement, a decomposition, a goal-level test, a steps-vs-phases
verdict, a FORM re-derivation, a plan-before-implementing check) produces the SAME conclusion every time it
re-runs against a fact that has not changed, so re-running it spends real cost for zero new information.
RE-VERIFICATION (rule-syntax, file-structure/AS-IS-survey/anti-duplication, content guardrails, the
self-check/report-close gate) checks the ACTUAL text a pass produced, which is new every time and can newly
fail every time — nothing about a narrower entry mode may ever shrink this half.

**WHEN a phased agent's own coordinating caller re-invokes it to fix an already-decided defect against
content that SAME chain already authored ⟶ the caller MAY declare a narrowed entry mode, skipping only the
phase(s) whose job is RE-DERIVATION, never the phase(s) whose job is RE-VERIFICATION.** A narrowed mode that
skips a verification phase is not an instance of this pattern — it is a different, unsanctioned shortcut
wearing this pattern's name.

## The HUNT-vs-VERIFY carve-out — a standing rule of this pattern, never a footnote

**NEVER let an adversarial/critic agent's own FIRST, COLD look at anything — a diff, a plan, a claim — be
replaced by a correction-mode-shaped entry.** This pattern legitimately covers only a VERIFY re-check of an
already-adjudicated finding; it never covers, and was never intended to cover, the first adversarial pass that
PRODUCES the finding in the first place. `grimorio.code-reviewer`'s own HUNT mode
(ref:agent/grimorio.code-reviewer/behavior.md#modes--hunt-cycle-1-vs-fix-verification-cycle-2) is the
standing example of the pass this carve-out protects — cycle 1 of any REWORK sequence, always run in full,
never narrowed by anything resembling this pattern.
