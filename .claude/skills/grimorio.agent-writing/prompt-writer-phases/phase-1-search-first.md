## The question this phase answers

What does grimorio already know about this specific artifact and task, before any judgment is applied? Nothing
else. This phase does not choose a level, does not choose FORM, does not draft a single rule — it only
establishes the FACT of what was asked, the FACT of what the target file(s) currently say, and the FACT of
whatever precedent already exists for this artifact TYPE, so Phase 2 has something real to plan against.

## Steps

1. **ALWAYS state this phase's own graph before doing anything else: a single SELF node — read the brief, open
   every named target file, check whether this task is a rewrite — and nothing else; this agent never invokes
   another agent, in any phase, ever.** The task handed to you here is already the one atomic item Phase 0's
   chain decomposed the agent's whole job into, so this step is satisfied by stating that in one line, per
   ref:skill/grimorio.agent-writing#3-steps--protocol's own already-atomic-brief clause — never a license to re-litigate
   the phase boundary agent:grimorio.system-keeper already approved.
2. **ALWAYS read the spec you were handed IN FULL and hold its content VERBATIM.** WHEN it reads like a
   compressed summary rather than the principal's own words ⟶ say so as a finding in this phase's own
   DELIVERABLE below, never guess at the gaps it left out.
3. **ALWAYS open every target file the brief names IN FULL before forming any view of what it currently says —
   never edit, and never plan, from a summary of any of them.**
4. **WHEN the task is a REWRITE or an audit of an existing file, rather than authoring new content ⟶ run the
   nine audit lenses (below) against the CURRENT file and file findings in their format, before anything is
   drafted.**
5. **ALWAYS surface whatever relevant precedent already exists for THIS artifact TYPE** — a comparable shell, a
   comparable behavior file, a comparable `SKILL.md`+topic pair, a comparable hook, a comparable
   `settings*.json` entry — so Phase 2's placement-verification step is not starting cold.
5b. **ALWAYS ALSO search for, and name explicitly, a concrete EXEMPLAR of the SOLUTION CONTENT/mechanism the
   spec asks you to author — distinct from step 5's artifact-TYPE precedent.** Artifact-type precedent answers
   "has a shell/behavior file/SKILL.md like this been authored before"; this step answers a different question —
   "has a problem shaped like the ONE THIS SPEC SOLVES actually been solved before, and how." A spec can be
   handed to you with no artifact-type precedent gap at all while its actual solution content is invented from
   nothing, and step 5 alone would never catch that. **WHEN no such exemplar exists in the corpus ⟶ say so
   plainly in this phase's own DELIVERABLE, rather than silently proceeding.** Full doctrine, the citation-vs-
   exemplar distinction, and the bound against turning this into a research phase:
   ref:skill/grimorio.reasoning-principles/project.exemplar-grounding.md.
6. **WHEN the spec you were handed spans multiple independent target files whose content is already fully, identically decided by `grimorio.system-keeper` — a literal, repeatable application, not a judgment call per target ⟶ name that plainly in this phase's own DELIVERABLE as a MECHANICAL-VOLUME finding.** This agent
   cannot act on it — Step 1 above already states it never spawns, and it holds no `Agent` tool at all, per its
   own frontmatter — so the finding is a RECOMMENDATION your own Phase 6 report carries back to
   `grimorio.system-keeper`, the only agent positioned to decide and execute a Haiku-tier same-type clone for
   it, per grimorio-conduct rule 20's clone exemption. **"No mechanical volume — every target needs genuine
   judgment" is the common, legitimate answer** — state it plainly rather than leaving the field silent.
   **WHEN this recommendation is acted on and a Haiku-tier clone is actually raised ⟶ its output is gated
   exactly as ref:skill/grimorio.agent-writing/system-keeper-phases/phase-4-authoring-coordination.md's own step 6
   states: never treated as authored or done, never landing on the clone's own say-so, until
   `grimorio.system-keeper`'s own Phase 5 reality check on that node actually completes.** This agent does not
   perform that review itself — it never spawns and never receives a child's report — so this recommendation
   is a flagged eligibility only, never the whole safeguard.
