## The pre-split behavior model (DROPPED 2026-07-17)

Before the brush-critic invocation-bias incident, the standard was: the agent file holds the steps,
rules, and output contract; skills hold only knowledge; "the agent file is the single source of truth
for what the agent does." Dropped 2026-07-17 — behavior inline in the agent file is now a defect, not
the standard. Nothing was deleted in the migration; behavior was moved intact into behavior files.

At the same time the levels were renamed: the old L0/L1/L2/L3 numbering retired in favor of the
semantic names **behavior · general · project · code** — do not reintroduce the numbers.
