## The question this phase answers

What is the topic actually being asked, and what independent slices/dimensions does it decompose into (minimal
overlap, full coverage)? Nothing else. This phase does not spawn anything, does not gather a single source, and
does not converge — it only establishes what the ONE topic is and how it splits, so Phase 2 has real, disjoint
slices to hand to a scout panel.

## Steps

1. **ALWAYS state this phase's own graph before doing anything else: a single SELF node — read the brief, frame
   the topic, decompose it into slices, decide the single-slice-collapse question — and nothing else; this
   agent never invokes another agent from this phase.** The task handed to you here is already the one atomic
   item Phase 0's chain decomposed the agent's whole job into.
2. **BEFORE framing the topic ⟶ state, as part of your own reasoning — never as a question back to your caller
   — your OBJECTIVE (the topic and slices you were actually asked to research, taken from the brief) and your
   EXIT CONDITION (what a converged, cited report on this topic looks like when it holds).** ->
   ref:skill/grimorio.reasoning-principles#state-your-objective-and-exit-condition-then-close-verified-or-could-not-hard-rule-ceo-2026-08-11,
   not restated here.
3. **ALWAYS frame the ONE topic** + the slices/dimensions that matter — the invoking prompt may name them
   directly; when it does, hold those names, never re-derive a different split just because you can.
4. **ALWAYS decompose into independent slices** — one per sub-tool, dimension, or source-type, minimal overlap,
   full coverage. ->
   ref:skill/grimorio.fan-out#part-1--decompose-spawn-in-parallel-synthesize's own "the axis IS the design" —
   deriving the axis is the work, never a fixed template applied on autopilot.
5. **NEVER decide.** Restated here, in this phase's own words, because this is the phase MOST EXPOSED to a
   caller quietly reframing a research topic into an implicit build-vs-buy question — "which of these should we
   adopt" dressed up as "research these options." **WHEN a topic's own phrasing already leans toward a decision
   ⟶ frame the slices as neutral gather targets anyway; the decision stays agent:grimorio.solution-architect's
   or the human's, never something this phase's own framing quietly pre-answers by how it names a slice.**
6. **ALWAYS decide the SINGLE-SLICE COLLAPSE question, here, and carry it forward as an explicit flag Phase 2
   must read — never leave it for Phase 2 to re-derive.** **WHEN step 4's decomposition genuinely yields only
   ONE slice — a small, narrow topic with no independent sub-dimension ⟶ record SINGLE-SLICE COLLAPSE: YES;**
   Phase 2's own scout-panel node collapses to "no spawn," and Phase 2 gathers it itself, sequentially, per its
   own Core rules' "Scale to the topic" line. **WHEN step 4 yields two or more genuinely independent slices ⟶
   record SINGLE-SLICE COLLAPSE: NO.**
